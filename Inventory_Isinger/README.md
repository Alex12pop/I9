# Самостоятельный проект: «Инвентарь»

**Автор:** Изингер Алексей  
**Группа:** ИСП-242  
**Тема:** Инвентарь

## Описание проекта

Консольное приложение для учёта инвентаря. Программа создаёт несколько позиций, выводит их характеристики и демонстрирует независимость объектов при изменении количества одной позиции.

## Главная сущность

**Главный класс:** `InventoryItem`.

Этот объект представляет одну позицию инвентаря. Он нужен программе, чтобы объединить характеристики конкретного предмета в одной сущности и работать с несколькими позициями по единой структуре.

## Какие данные хранит объект

- `Name` (`string`) — наименование предмета;
- `Category` (`string`) — категория;
- `Quantity` (`int`) — количество единиц;
- `Price` (`decimal`) — цена одной единицы;
- `IsAvailable` (`bool`) — доступность позиции.

В классе пять полей и четыре разных типа данных (`string`, `int`, `decimal`, `bool`).

## Конструктор

Через конструктор передаются все исходные характеристики позиции: название, категория, количество, цена и доступность. Конструктор сохраняет параметры в поля объекта.

## Автоматические значения

Стоимость всей позиции отдельно не хранится: она вычисляется при выводе как `Quantity * Price`. Это производное значение, поэтому нет необходимости передавать его в конструктор или хранить отдельно — так оно не рассинхронизируется с количеством и ценой.

Дополнительно для всех новых объектов не задаётся автоматическое значение полей: в рамках задания исходные данные позиции явно передаются через конструктор.

## Созданные объекты

1. Ноутбук Lenovo — электроника, 2 шт.
2. Мышь Logitech — периферия, 5 шт.
3. Клавиатура механическая — периферия, 3 шт.

У объектов разные значения полей. После создания программа меняет количество только у объекта «Мышь Logitech», показывая независимость состояния остальных объектов.

## Запуск

Требуется установленный .NET SDK 8.0 или новее.

```bash
dotnet run
```
